    How to use this worksheet
    1. Start blank and record only established facts. “On the desk” is not the same as “held by Iris.”
    2. Save a checkpoint, then edit the facts established by the next scene.
    3. Check the differences against your conversation. Leave unknown facts unknown.
    4. Download the prompt and paste it into your chosen chat interface if appropriate. Recheck the reply; this worksheet does not update any platform automatically.
